# 视觉识别与版式还原

参考图扩写按“识别证据 → 画布骨架 → 媒介层次 → 人物与局部”推进。识别服务于还原，不取代看图。

## 识别层级

- 清楚的作品标题、Logo、独特标志组合，以及充分可辨的虚构角色：主动给出对应名称，将其设计语言落实到字形、图形和版式中。
- 只有相似配色、衣装或气氛：描述可见风格，不猜一个作品填空。普通生活照无需强加IP。
- 使用作品标志的同人、照片拼贴或改编物料：描述“采用某作品标志／视觉语言”，作品名称不等于图片的官方来源。辨认作品文字不意味着辨认照片中的真人。
- 用户明确提供名称可沿用；明显冲突时区分用户要求的改编与原图事实。用户给了新画幅或去除标志要求，以修改要求为准。

## 版式先于细节

先固定横竖画幅、主视觉占比、画格数量和斜边、粗细分隔、主标题与人物的覆盖关系、缩略图带、底部信息区。然后描述照片里的具体人物、装备与灯光。复合海报不因标题熟悉而变成该系列的标准封面。

清晰的画内作品标志与排版文字属于内容，截图搜索按钮等界面覆盖物属于应省略的干扰；两者分别处理。模糊小字保留信息密度与区域，无法辨读时不编造文字，也不擅自替换成虚构发行标记。

## 媒介与证据

旧印刷感、照片颗粒、压缩细节融合、柔软边缘与清楚字标分别绑定对应区域；不把所有局部统一锐化或统一打光。可将“像旧杂志扫描件”作为视觉质感描述，不将其写成已查证的制作历史。人物脸型、耳饰、服装领口等只写可见内容，不用常见人物模板补齐看不清的细节。

## 诊断示例：游戏标志写真拼贴

若画面明确出现“grand theft auto”与绿色罗马数字V，可写“采用《Grand Theft Auto》标题标志与封面拼贴语言的竖版女性写真海报”，随后还原实际倾斜画格、粗黑框、跨格标题、四张小图和底部信息区。V中的雕刻线纹与人物头巾上的佩斯利花纹分别描述，绶带位置按图确认。这个示例用于示范识别和绑定，不把其构图、低清质感或绿黑配色迁移到其他图片。
