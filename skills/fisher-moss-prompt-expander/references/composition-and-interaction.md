# 构图、动作与忠实性

## 两种补全尺度

参考图的“明确可见”包含主体数量、占画比例、服装大形、动作、目光、接触点和色调。完整保留。模糊细节写“浅色饰件”“细长器具”等低粒度称谓。遮挡是画面的事实，可写“手藏在宽袖中”，无需补出手指或武器。对无法辨认的小物件，省略通常优于猜出具体用途。

一句话创作需要自主完成未指定项，明确要求是锚点。先选一个瞬间和主焦点，再决定空间、动作和照明，继续深入到每个主要维度的可见细节，交付入口要求的详细长版。例如“巨树下的仙城”可深入设计水岸、栈道、窗灯、树皮与建筑连接、倒影和空气层次，不必另加神龙、军队和法阵。用户只说两人交谈，就把谈话瞬间设计充分，不改成亲吻或战斗。画面简洁与描述充分可以同时成立：白墙自拍可以细写裁切、肩颈姿态、衣料、肤色和窗光，无需把背景填满。

图＋修改先记录保留项和修改项，在最终提示词中直接描述修改后的完整画面。白天改雨夜需要同步调整地面、衣料、天空、光源与倒影；不能只在原来的烈日段落末尾添加“夜晚”。

## 内部主体绑定

对主要人物用短记录即可，无需输出：

“A：画面左、坐姿、浅粉衣、看向右上B、可见手停在胸前；B：画面右、站姿、深褐宽袖、低头看A、伸出缠布的手、另一手持短笛。”

空间方位默认以观看者为准。只有跨视图设定板或动作需要时使用人物解剖学左右，并明确区分。身体朝右不等于眼睛朝右，转头回望要分别写。手部写清伸出方向、掌指大势、持物与遮挡即可，手指不可见时不细分每一根。

## 接触与支撑

坐在何处、膝盖如何接地、道具由谁承托、红绳从何处到何处，是互动可信度的关键。描述触碰时写明对象与位置，例如“男子扶住女子上臂”，避免“双方互相扶着”。尚未接触就保留间隙。衣袖、头发与器物的遮挡应兼容相同动作。

全身动作需有重心与支撑；半身图先固定裁切下缘，再决定可见肢体与家具。胸口或腰上取景时，放在腿上的手位于画外；要让手入镜，可以在自由创作中将它放到胸前或提高到取景范围内，参考图则保留原有姿态和裁切。人物和背景都按镜头可见范围展开，避免为了丰富细节同时声称看见被裁掉的身体部位。动作瞬间统一风向与惯性，但不要为静态肖像自动增加飘带和粒子。

## 写作顺序

先核心场景和关系，再准确构图，然后分主体展开。复杂双人可依次写A造型、A动作、B造型、B动作、双方接触；接触作为主焦点时可以提前。换主体时重复“左侧女子”“右侧男子”等身份，少用连续的“他/她/另一只”。

参考图数量与内容较多时按图片序号建立边界，不让上一张的服饰、标题和光色渗入下一张。用户要求每次一张时保留已完成序号；仅要求顺序时直接逐块完成。

## 常见失真与改写

“女子举手，男子抓住她” → “女子的手停在胸前，男子伸出的手仍与她相隔一小段距离。”

“古筝摆在桌上”但器物仅露一角 → “画面下缘露出深色木质弦乐器局部”。

“两人背靠背，都回头对视”但图中望向两侧 → 分别写两人的身体和目光，保留相反视线。

“巨大建筑充满画面，人物脸部微表情清楚” → 根据远景尺度优先保留人物剪影和姿势，把脸部细节降为次要。
