# 维护验收用例

仅用于创建或修改技能后验收，不在每次用户扩写时加载。用真实输入检查输出行为，不检查是否复用了某句固定措辞。图像用例缺少原图时标记未执行，不以文字模拟冒充看图测试。

| 编号 | 输入 | 关键观察 |
|---|---|---|
| A | 一句话：白衣女子坐在竹林温泉里，身后有巨大狐狸尾巴 | 完整创作构图、尾巴体积、水线、统一照明；没有询问非关键细节 |
| B | [花下参考图](../assets/reference-inputs.md)，无附加要求 | 左坐右站、仰视与低头、手尚未接触；不臆定局部弦乐器种类 |
| C | 一句话：三位旅人夜宿车亭，一人吹笛，一人修弓，一人煮茶 | 三人衣物、动作与道具分别绑定；场景是同一瞬间 |
| D | 一句话：荒原行者面对山岳般巨龙 | 以比例、参照和遮挡表现尺度，保留行者；无矛盾近景微表情 |
| E | 一句话：巨树下的水上仙城，白花和瀑布 | 环境为主，空间连续，有焦点与留白；不强加主角或战斗 |
| F | 一句话：水墨剑客海报，标题“一剑入江湖” | 文案保真，水墨媒介、字体与留白；不摄影化 |
| G | 花下参考图＋仅把男子外袍改为墨绿，保持人物动作 | 衣料色彩与邻近反光更新，人物姿势构图保留；不更换道具 |
| H | 同时提供B与[现代时尚图](../assets/reference-inputs.md)，要求依次全部输出 | 同轮两份独立代码块，不融合人物衣服；若改为每次一张只输出当前 |
| I | 一句话：一个亚洲女孩，在家中自拍。 | 默认约1500—2500中文字，原句虽短仍完整设计；自拍成像方式明确，镜头与手机位置相容，保持日常场景 |
| J | 一句话：一个亚洲女孩，在家中自拍。简短，200字以内。 | 遵守短版要求，保留核心构图、姿态和光线；不强制扩写至默认长版 |

检查通用不变量：用户硬要求保留、主体不串位、遮挡不乱猜、光源不冲突、开头可重建核心画面、没有无信息增量的重复段落、格式与图片顺序正确。I/J配对检查默认长版与显式短版是否实际分流；统计正文汉字数和总字符数辅助判断展开程度，长度合格本身不代表内容质量合格。

记录测试输入、输出位置、观察到的问题和未测项。纯文本或人工图像描述验收不代表生成模型实测；如果用户要求验证出图，需另选明确目标模型、参数及实际输入，不宣称跨模型一致。

## 新增分支验收

| 编号 | 输入 | 关键观察 |
|---|---|---|
| K | 两个女生在咖啡店喝咖啡然后手持自拍；分别追加对镜、第三方拍摄版本 | 三种机位不混用，人数和手部任务稳定 |
| L | 花下图人物和姿势，换成时尚图的黑色皮衣，保留花下环境 | 只迁移指定服装；脸、人数、道具与环境不被服饰图覆盖 |
| M | 两位原创武侠角色设定板，白袍剑客右肩护甲，青衣女侠左腰佩剑，每人正背侧视图 | 角色与视图两层绑定，解剖学左右跨视图一致 |
| N | 女子侧脸剪影内放三段古装情侣场景，标题“灯下归人” | 外轮廓完整，内部场景边界和标题位置清楚 |
| O | 黑衣剑客背后同心圆剑阵，剑尖朝外 | 剑尖方向、近远大小、人物遮挡一致 |

执行状态见[验收记录](../validation/README.md)。本表是用例库，不代表全部已执行。

## P：视觉来源与版式

输入含清晰作品标志的写真拼贴参考图，仅要求图转提示词。检查有依据的作品识别、官方归属区别、原图横竖与分格、标题遮挡、底部信息和媒介差异。对照无作品标志的普通自拍与原创水墨图，检查不会凭配色猜IP。执行范围见验收记录。
