# 分类与模块

先选主要画面骨架，然后叠加本次必需模块。题材如古装、都市、赛博只是素材背景，媒介另选。以下九类用于检索案例，允许组合。

| 案例类别 | 骨架/模块 | 优先解决 |
|---|---|---|
| 单人肖像 | 单主体 | 画幅裁切、脸部角度、目光、手和道具、衣饰轮廓 |
| 双人互动 | 双人 | 站坐高度、相向关系、接触或距离、双方可见手部 |
| 多人群像与仪式 | 群像 | 主次、队列或分组、独立人物身份、通道与视线 |
| 巨物与奇观 | 单主体/环境＋尺度 | 参照物、占画比例、透视、遮挡和空气层次 |
| 法术与动作 | 任一骨架＋动作特效 | 一个动作瞬间、力量来源、方向和环境反馈 |
| 建筑环境 | 环境 | 前中后景、通行与结构、焦点、材质和自然条件 |
| 现代时尚摄影 | 单人/双人/群像＋摄影 | 线条、裁切、棚光、服装与道具、留白 |
| 海报与图形 | 任一骨架＋版式 | 图文层级、负空间、媒介与图形融合 |
| 角色设定板 | 单主体/群像＋设定板 | 同一造型的跨视图一致性、细节与材料分区 |

## 人物骨架

单人根据主体需求选择半身或全身，不因丰富细节把近景改成全身。参考图主体美貌保留其面部特征，使用清丽、自然、精致等整体审美描述；不自动统一成尖下巴、浓妆或塑料肌肤。

双人先确定左右、站坐与远近，再安排每个人的动作。情绪用可见行为表达，如仰视、手停在接触前、紧绷肩线，不把长篇人物背景故事塞进静态提示词。

群像按主要人物、次要人物组、远景人群组织。重要人物逐个绑定衣服和道具；重复队列按共同服装和差异动作描述。图片人物数量明确时保留数量，被遮挡或过小时不伪造精确计数。主角不能被新加的配角抢走。

## 环境与尺度

环境主导场景用三个空间层次建立纵深，但不机械要求每层都有物件。保留参考图的空天、暗水或空地。建筑确定屋顶—承重—基座关系，桥道与门口接通，悬浮建筑应表现其幻想性质。

巨物的巨大来自人、军队、楼阁或山体参照及遮挡，不靠不断重复“万丈”。确定巨物占画比例与是否被裁切，前景人是否仍能看见。发光巨物照亮邻近环境，实体巨物有遮光与接触；不要无依据地添加灾难或破坏。

## 动作与法术

静态图描述一个可同时成立的瞬间，不串联起手、挥砍、命中、落地四个时间。先固定人物姿势，再确定特效从哪里出现、沿什么方向延伸、哪里最亮、怎样作用于衣发尘雾。剑阵、文字阵和能量法相分别保留独特形状，不一律变成随机闪电。

## 时尚、海报、设定板

时尚摄影用服装体块、肤色和道具建立视觉线条。极简背景保留极简，红绳不自动变成束缚，持枪画面不自动添加枪火。

海报先区分视觉主体、标题、辅助文字、装饰图形。明确文字位于人物前还是后，哪些被裁切或遮住。双重曝光说明外轮廓和轮廓内部各自装入哪些场景。水墨画保留笔势和纸面留白，不能用真实空间物理规则抹掉有意的图形融合。

单角色设定板先写该角色母设定，再展开正背侧视图和局部放大；多角色板则先给各角色独立母设定，逐个派生视图，区分角色间差异和同角色跨视图一致性。解剖学左右一致：角色右臂的护甲在正面和背面应出现在画面不同侧。单独列头饰、武器、织物或材质样本时沿用所属角色母设定。具体分配见 [模式决策](mode-decisions.md)。参考素材缩略图不冒充已有来源或授权。

## 组合示例

- 狐灵温泉：单主体＋幻想生物；主要处理尾根遮挡、尾巴弧线、水面接触。
- 金色文字法阵：单主体＋法术；字是场景内形体，不是海报标题。
- 赛博锦鲤巡游：环境＋巨物＋全息；前景实体灯笼遮挡投影，高楼提供尺度。
- 中秋旅行车群像：群像＋节庆海报＋3D；先分配角色，再放灯与标题。
- 白底红线情侣：双人＋时尚；准确处理绳线与双手，保留白色负空间。
