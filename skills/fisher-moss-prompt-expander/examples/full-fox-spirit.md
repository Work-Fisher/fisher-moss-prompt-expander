# 完整案例：竹林温泉狐灵

输入：白衣女子坐在竹林温泉里，身后有巨大的狐狸尾巴。

模式：一句话自由创作。沿用温泉、白衣女子与巨型狐尾，在同一场景内展开机位、姿态、干湿材质及照明。
