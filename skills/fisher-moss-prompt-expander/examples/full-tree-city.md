# 巨树水城：完整长版案例

用户输入：巨树下的水上仙城，白花，远处瀑布。

模式：一句话自由创作。补全岸线、建筑通路、巨树尺度与暮色照明，以环境结构展开原句。

```text
一幅精细的东方幻想环境概念画：苍老巨树庇护着依水而建的仙城，深青瓦顶、朱褐木廊与成片白花沿弯曲岸线铺展，峡谷深处一条银白瀑布从高崖落下。画面捕捉日落之后、天空仍留余光的安静时刻，屋内灯火刚刚亮起，水汽停留在远处谷口。整体为横向宽幅全景，城市是可进入、可行走的真实空间，宏大的树冠与微小的生活痕迹共同建立隐世城池的尺度。

取景位置设在水道南岸一处略高于水面的石阶上，以接近站立行人的视线向对岸观看，镜头轻微仰起，兼顾近处水面与巨树的主枝。左侧树干占画宽约四分之一，树冠伸出上缘，粗枝横跨中上部形成遮蔽天空的天然顶棚。右侧保留一条狭长而明亮的峡谷开口，让瀑布成为远景落点。水面占下方约三成，岸线从左下向中央后方弯入，再转向右侧谷口，视线顺着水路逐层深入。

巨树根部不是平直插入地面，而是数条隆起的板根沿岩岸舒展，主根之间夹着潮湿石壁、积土和低矮草丛。最粗的一条树根从左侧向中央伸出，在岸边抬高后重新没入岩石，形成高于人身的天然洞口，洞后可见一段连廊。树皮以深褐、灰棕为基底，纵向沟槽顺着扭转的生长方向延伸，迎光脊面干燥而浅，背光缝隙聚集深绿苔藓，靠近水线的木质颜色更深。

树冠由几组方向明确的主枝承托，每组枝条外侧逐渐分出较细的枝梢，不把整个上方填成均匀的绿色团块。左上叶片重叠紧密，接近黑绿；中央枝隙漏出少量灰蓝天空，右端的新叶被谷口余光照出薄而柔的边缘。零星白花嵌在有细枝支撑的位置，浓密花景主要留给岸边独立的花树。几束细长气根垂至高层屋檐附近，其末端与檐角错开，让树木与建筑之间仍能辨认出可呼吸的空隙。

城市的基座由贴合岸势的灰石挡墙构成，挡墙下部浸水发暗，上部能看见不规则砌缝和浅色磨损。最靠近镜头的临水木殿位于左下，屋顶低而宽，两层出檐压住暖亮的内部空间，瓦片顺坡密排，檐口有轻微风化。朱褐立柱沿石台一字排开，柱脚立在石础上，与潮湿水面保持距离。殿前六七级石阶下到小码头，最下两级被水淹没，阶沿积着少量漂来的花瓣。

一条木栈道从近殿右侧接出，贴着挡墙绕过树根，抵达中央略高的院落，栏杆的转折与地面连续对应。遇到从岩壁突出的巨根时，栈道通过短石阶上升，再在根后恢复平缓。中央水渠上架一座不高的单孔石桥，桥拱完整露出水面，桥下阴影与倒影形成上下呼应。桥面朝右岸的小街延伸，小街两侧屋檐之间保留细长的通行缝隙，所有平台都有清楚的承托或与山体连接的部分。

中央偏右的主殿坐落在第二级台地，宽阔的深青屋顶比周围民居高出一层，但不与巨树争夺最高点。檐角轻轻上扬，屋脊线条沉稳，瓦面只有朝向天空的部分带冷灰反光。木构立面由廊柱划成有节奏的明暗区，门内的琥珀灯光被窗棂分隔，进深处仍保留黑暗。再往后的楼阁依崖逐层抬升，各层基座嵌进岩壁，近处屋顶遮住后方建筑的一部分下层，形成可信的坡地叠建关系。

白花沿院墙、桥头和高低露台分成几组，每组都有可辨识的灰褐树干和展开方向，密集花簇之间露出暗色枝缝。近处花瓣偏暖象牙白，薄边透过余光，阴面带很浅的灰紫；中景白花呈柔和的灰白，与朱褐柱子互相衬托；更远的花树压缩为较淡的细碎色面。桥边一枝白花伸到水面上方，既遮住少量栏杆，也在水里留下松散的浅色倒影，少量落瓣顺水汇在岸石旁。

右下近景露出一座低矮石灯和半截岸边栏柱，作为最近的空间参照。石灯的宽顶盖略带青苔，边缘被长期雨水磨钝，灯室内一团小而稳定的暖光只照亮开孔内壁与下方石座，亮度不足以照透整个水道。栏柱和石灯遮住中景的一小部分，轮廓较深但有可见的灰石细节。画面左侧码头系着一只窄木船，船头与岸边之间留出细窄水缝，绳索从船首系向木桩，船舱内安静地放着一只盖好的竹筐。

水面保持缓慢流动，近岸呈深墨绿，开阔处混入灰蓝天空的反射，靠近灯窗的位置出现断续的橙金细线。倒影的位置与上方实体对应，树干在左侧形成宽阔暗影，主殿与花树的影像随着细密横纹被拉散，不能像另一座清晰倒置的城市。水道转弯处的远水更浅，几条低对比波纹带出流向；最靠近镜头的区域可见沉在浅水里的石阶边缘，水下轮廓因折射而轻微错位。

远景瀑布位于右侧峡谷深处，水流从高处岩台翻落，在垂直落差中分出几束宽窄不同的白色水带，后方偶尔露出暗灰岩面。瀑布下端被更近的屋顶、花树与水雾遮住，水雾集中在谷底后缓慢扩散，不覆盖前景建筑。两侧峭壁以大块灰褐岩层建立山体重量，近处裂缝清楚，越远越趋于蓝灰。瀑布通向城市水道的方向由谷底的浅色水面暗示，空间关系连续，远处高度通过微小树丛和岩台宽度体现。

照明由谷口残留的冷色天光和城内少量暖灯共同组织，冷光从右后方进入，照亮花冠上沿、屋顶外坡与瀑布水汽，巨树下面形成深而通透的阴影。暖光集中在门窗、桥头和树根旁的小灯处，在邻近柱面与石阶上形成逐渐衰减的反射。整体色彩以墨绿、青灰、木褐、象牙白为主，琥珀金只作有限点亮。近景保留木纹、石缝与湿痕，中景强调轮廓和建筑层次，远景让边缘随空气变软；以细腻但有笔触的概念绘画质感完成，画面不带标题、水印或界面。
```
