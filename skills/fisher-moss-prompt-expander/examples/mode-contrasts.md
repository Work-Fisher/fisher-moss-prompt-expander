# 模式对照：短片段，不是完整交付长度样板

## 咖啡店双人自拍的三种机位

同一简报：两位成年女生在咖啡店喝咖啡，手持自拍。

- 前置成片：左侧女生伸臂持机，镜头就是手机视点，握机手和手机不入镜。右侧女生靠近，双眼看向同一镜头；两只杯子放在可见桌缘，手势与取景一致。
- 对镜版本：镜面收进并坐二人和桌缘，持机者的手机反射位于侧脸外侧，同伴的脸完整可见。两人看手机屏幕，镜框和反射中的背景建立视点。镜中衣物和手臂使用同一左右约定。
- 外部观察：摄影机从邻桌斜侧方拍摄，能看到伸出的手机背面与两人的三分之二侧脸。她们看自己的手机，不看外部摄影机。此版本是“正在自拍”的场景照片。

这三段互为选择，不可拼接成一张图的提示词。

## 三图融合分工

输入：A中的古装人物，穿B的现代黑色外套，放进C的咖啡店；保持A的坐姿，改成真人摄影。

内部方案：A提供人数、面部特征和坐姿；B只提供外套剪裁和材质，不带入B的人脸、手枪或红底；C提供桌椅、窗光和背景。保留A手臂的主要姿势，适配现代袖口与桌面高度。若手中原道具未要求修改，保留；如与咖啡店空间严重冲突，应依据明确要求处理，不能悄悄换掉。

描述片段：人物保持原有侧坐与转头方向，身穿短款黑色皮外套，袖口沿弯曲的肘部形成反光褶皱；咖啡店窗光落在其面颊和外套肩线，后方木吧台与座椅具有同一透视。面部特征仍属于主参考人物，背景不带入服装参考图的红色字母。

## 双重曝光海报

```text
竖幅古装爱情海报，以一位女子朝左的深色侧脸剪影作为主轮廓，发髻、鼻尖、嘴唇和颈线完整可辨。剪影内部上下分布三段暖灯下的双人场景：上方廊内相望，中部窗边靠近，下方桌前对坐。每段保留同一对人物的服装识别点，场景之间用暗枝与纸纹过渡。外部为浅赭色旧纸背景，红绸越过轮廓边缘作为装饰，标题“灯下归人”位于右下外部留白，不遮住侧脸轮廓。
```

## 径向剑阵

```text
黑衣人物位于庭院中央，背后银色长剑沿同心圆均匀展开，剑柄靠近内圈、剑尖指向外侧。圆阵略向后倾，近处下缘剑体较大，远处上缘略短，人物遮住中部少量剑身。银光附着剑刃形成细窄亮线，庭院屋瓦接收少量冷色反射。以清楚的放射结构呈现剑阵，人物面前留出可辨认的暗部间隙。
```

## 双角色设定板

输入：角色A白袍，解剖学右臂重甲；角色B短绿衣，解剖学左腰挂刀，两人都需要正背视图。

```text
浅灰背景分成左右两个角色区，每区各有同一人的正面与背面全身图。左区A保持白色长袍和右臂重甲：正面时重甲在观看者左侧，背面时在观看者右侧。右区B保持短绿衣与左腰刀：正面刀在观看者右侧，背面刀在观看者左侧。A的高冠、长袍和重甲不迁移到B，B的短衣、腰刀和靴子不迁移到A。四幅视图脚底对齐，以相同缩放显示两个角色真实身高差。
```
